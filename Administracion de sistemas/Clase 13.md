# Gestión de interesados y comunicaciones
>[!Definition] Gestion de interesados
>Permite plantear acciones para cada uno de los actores de la organización. Al verse afectados positiva o negativamentes, pueden boicotear al proyecto y afectar la finalización

- **Stakeholder** Es una persona o entidad que puede verse afectado positiva o negativamente por el proyecto. Es alguien que tenga interés y pueda influenciar en el proyecto
### Matriz de interesados
- Quien es
- Cargo o posicion
- Rol en proyecto
- Informacion de contacto
- Requerimientos -> Requerimientos de esta persona en el proyecto
- Nivel de influencia
- Expectativas de proyecto -> Que espera la persona del proyecto
- Clasificacion -> prioriza para valorar el feedback o comunicacion de cada stakeholder
Me interesa saber quien influencia mi proyecto, a quien pedir ayuda, a quien acudir para avanzar o pedir mas presupuesto. Quiero saber que quieren tambien del proyecto

### Matriz de interesados estrategia
Tomar estrategias con interesados o stakeholders segun su nivel de clasificacion
- nombre
- Nivel de influencia
- Analisis de impacto o que quiere: Tecnico, operativo, organizacional o personas
- Estrategia para que el impacto sea lo mejor para mi proyecto. No repetir entre interesados. Basicamente, como hacer que *esa persona* este contenta

## Gestion de comunicacinoes
Como se comunican los avances, hitos, problemas, etc del proyecto
### mensajes/reuniones OBLIGATORIAS
- Inicio de proyecto (empiezo por las planificaciones/gestion)
- Cierre de proyecto
- Kickoff (post-planificacion, se comienza a trabajar)
- Demos
- Presentacion comercial
- diarias o de status
### Matriz de comunicaciones
Debo definir
- Que informacion se necesitará
- Quién necesitará esta información -> Lista de interesados
- Cuando se necesitará esta información -> Lista de frecuencias
- Como se entregará esta informacion -> Eleccion de medios (formales e informalese)
Ser generico en la matriz (no hacer una fila por rol, agrupar por grupos)
#### Matriz de reuniones
- Tipo de reunion
- Frecuencia
- Responsable de la minuta
- Integrantes
