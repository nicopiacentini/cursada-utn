### Definiciones
#### Variable controlada
Es la cantidad o condicion que se mide y controla. Es lo que yo quiero limitar o controlar. Segun los sistemas puede ser:
- Voltage
- Velocidad
- Posicion
#### Controlar
Es medir el valor de la variable de control y aplicar la variable manipulada para corregir o limitar una desviacion. Lo realiza un controlador que debe **sensar** para modificar a la variable controlada.
- La variable manipulada es aquello que yo modifico para controlar o limitar a la variable de control. Puede ser por ejemplo amperaje
#### Planta
Equipo sobre el cual quiero realizar la accion de control. Es un equipo o maquinaria que funcionan juntos
#### Sistema
Conjunto de elementos que actuan juntos para un objetivo. Es decir incluye la planta, controladores, actuadores, etc.
#### Perturbacion
Señal que tiende a afectar la salida de mi sistema.
