# Introducción a Ciencia de Datos
## Introducción a la materia

## ¿Qué es Ciencia de Datos?
La Ciencia de Datos es una disciplina interdisciplinaria que se encarga de recolectar, procesar, analizar e interpretar grandes volúmenes de datos para extraer conocimiento útil que ayude a tomar decisiones. Dicho conocimiento no se obtiene de forma directa al ver los datos, sino que deben procesarse. 

Combina conocimientos de:
- Matemática y Estadística
- Informática y Programación
- Inteligencia Artificial
- Conocimiento del dominio (negocios, salud, ciencia, etc.)

Su **objetivo** **principal** es **transformar** datos en **información** y **conocimiento**.

## Enfoque en la Ingeniería Informática
>[!definition] Ciencia de datos en ingeniería informática
> La Ciencia de Datos es un área estratégica dentro de la Ingeniería Informática, orientada al diseño, desarrollo e implementación de sistemas computacionales capaces de *procesar*, *analizar* y *modelar* **grandes volúmenes de datos**, con el objetivo de **generar conocimiento** accionable.

###### Como se aborda la ciencia de datos
Desde la Ingeniería Informática, la Ciencia de Datos se aborda como:
- Un problema de ingeniería de software
- Un problema algorítmico y computacional
- Un sistema escalable y eficiente

Se apoya en:
- Algoritmos y estructuras de datos
- Estadística computacional
- Sistemas distribuidos
- Inteligencia Artificial y Machine Learning
> Los datos son tantos que debo correr el código en maquinas poderosas. 
## Historia de la Ciencia de Datos

**Siglo XVII–XIX:**
- Desarrollo de la estadística (probabilidad, censos, estudios poblacionales)
- Uso de datos para gobiernos y ciencia

**Siglo XX:**
- Aparición de las computadoras
- Análisis estadístico automatizado
- Nacen conceptos como *análisis de datos* y *minería de datos*

## Evolución de la Ciencia de Datos

**Fundamentos previos:**
- **Estadística computacional**: aplicación de métodos estadísticos mediante computadoras
- **Bases de datos**: modelos relacionales (Codd) y posteriormente NoSQL. Sirve para guardar y transformar datos para analisis.
- **Ingeniería de software**: desarrollo de sistemas robustos y mantenibles

**Minería de datos y Big Data:**
**Mineria de datos** - Procesar y aplicar algoritmos a datos para obtener patrones subyacentes de ellos.
- Décadas de 1980–1990: aparición de la minería de datos
**Big Data** - Datos que cumplen con:
  - Volumen - Alto volumen
  - Velocidad
  - Variedad
  - Veracidad - Deben ser chequeados
  - Valor

**Ciencia de Datos moderna:**
- Integración de Big Data, Machine Learning y computación distribuida
	- Distribuido para procesar datos paralelamente
- Uso de arquitecturas escalables para análisis masivo de datos
	- Arquitecturas escalables: Puedo agregar maquinas para procesar en paralelo
- Automatización del análisis mediante algoritmos inteligentes
	- Conceptos de ciencia de datos moderna
	- **Explainability**: Que el modelo pueda explicar por que llega a una conclusión

**Línea de tiempo:**
- **Antes de 1960:** La estadística y las matemáticas eran los principales métodos para analizar datos. Se usaban principalmente en el ámbito académico y gubernamental.
- **1960–1980:** Nace el procesamiento de datos.
- **1990–2000:** La popularización de Internet genera una cantidad sin precedentes de datos. Se empiezan a desarrollar nuevas herramientas y algoritmos para manejar este "Big Data". Las bases de datos y los lenguajes de programación específicos para el análisis de datos como SQL hacen su aparición.
- **2000–2010:** Convergencia de la estadística, la informática y el conocimiento del negocio. Se empieza a hablar de "Ciencia de Datos" como un campo propio. Aparecen lenguajes de programación como R y Python con bibliotecas específicas para análisis de datos y aprendizaje automático. Aparece la **predicción**
- **2010–Hoy:** El aprendizaje automático y la inteligencia artificial se convierten en componentes centrales de la ciencia de datos. Nacen frameworks como TensorFlow y PyTorch que facilitan la construcción de modelos de aprendizaje profundo. Aumenta la demanda de especialización: científicos de datos, ingenieros de datos, analistas de datos, etc.

## Proceso de la Ciencia de Datos

Lo hace el data engineer. Se pueden obtener de:
- Bases de datos
- Sensores
- Redes sociales
- Encuestas

**Limpieza de datos**
Lo hace el cientifico de datos. Lo que se hace es:
- Eliminar errores
- Corregir datos incompletos
- Unificar formatos

**Análisis de datos**
Lo hace el cientifico de datos
- Estadísticas
- Gráficos
- Modelos matemáticos

**Modelado**
Lo hace el cientifico de datos. Es de lo que va la materia
- Machine Learning
- Inteligencia Artificial
- Predicciones

**Interpretación y comunicación**
Es para que lo vea el cliente. Lo hace el cientifico de datos
- Informes
- Visualizaciones
- Toma de decisiones

## Metodología en la Ciencia de Datos
Es la parte previa al código. 
**Análisis del problema**
- Requerimientos funcionales y no funcionales
- Restricciones computacionales

**Arquitectura del sistema**
- Diseño de pipelines de datos (ingeniero de datos)
- Elección de tecnologías (batch / streaming)
	- **Batch** - Procesar un grupo de datos cada x tiempo (frecuencia)
	- **Streaming** - Procesar datos on demand, a medida que llegan

**Gestión de datos**
Se busca un ingeniero en datos que busque y filtre los datos de:
- Bases de datos SQL y NoSQL
- Data lakes y data warehouses

**Preprocesamiento**
- Limpieza y transformación
- Feature engineering

**Modelado algorítmico**
- Selección de algoritmos
- Entrenamiento y validación
- Optimización y tuning

**Despliegue y mantenimiento**
- APIs de modelos
- Integración continua (CI/CD), dataops o mlops
- Monitoreo de desempeño
